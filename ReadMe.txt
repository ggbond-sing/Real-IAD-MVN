Real-IAD-MVN

1. Extract realiad_mvn_raw/<category>.zip into realiad_mvn_raw/.
2. Extract realiad_mvn_jsons.zip into the dataset root.
3. JSON path fields are relative to realiad_mvn_raw/.
4. Original image bytes and within-category directories are retained.
5. The dataset uses CC BY-NC-SA 4.0. See LICENSE.txt.
6. See README.md for the JSON index fields and category statistics.
